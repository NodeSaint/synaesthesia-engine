# Synaesthesia Engine

An interactive, audio-reactive generative visualizer that runs entirely in the browser. A single self-contained HTML file — no build step, no dependencies.

**Live demo:** https://nodesaint.github.io/synaesthesia-engine/

## Run locally

Open `index.html` in any modern browser, or serve it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## About

`index.html` contains all markup, styles, and logic. It renders a real-time
visual field to a `<canvas>` with a minimal HUD and control surface. Click
**BEGIN** to start.
